# Reinforcement Learning for Insulin Dosage Control

Проект посвящён исследованию методов обучения с подкреплением для автоматического дозирования инсулина у пациентов с сахарным диабетом I типа. В работе используется симуляционная среда `simglucose`, основанная на модели UVa/Padova, а основной исследуемый алгоритм — **Proximal Policy Optimization (PPO)**. :contentReference[oaicite:0]{index=0}

---

## Описание проекта

Система искусственной поджелудочной железы состоит из:

- сенсора непрерывного мониторинга глюкозы (CGM),
- инсулиновой помпы,
- алгоритма управления подачей инсулина.

Задача управления осложняется:

- нелинейностью глюкозо-инсулиновой системы,
- задержками действия инсулина,
- частичной наблюдаемостью,
- стохастическими сценариями питания,
- различиями между пациентами.

В проекте исследуется применение PPO как устойчивого и воспроизводимого метода обучения с подкреплением для непрерывного управления дозировкой инсулина. :contentReference[oaicite:1]{index=1}

## Среда моделирования

Используется симулятор `simglucose`, основанный на модели UVa/Padova.

Поддерживаются три группы виртуальных пациентов:

* дети,
* подростки,
* взрослые.

Каждый пациент имеет индивидуальные физиологические параметры. Управление осуществляется через инсулиновую помпу, а наблюдения поступают от CGM-сенсора. 

---

## Постановка задачи

Задача формализуется как **POMDP** (частично наблюдаемый марковский процесс):

[
P = (S, A, O, P, Z, R, \gamma)
]

### Пространство действий

Агент выбирает скорость подачи инсулина:

[
a_t \in [0, u_{max}]
]

### Наблюдения

Агент получает:

* текущий уровень глюкозы,
* динамику изменения глюкозы,
* предыдущее действие,
* признаки пищеварения,
* текущую углеводную нагрузку.

---

## PPO-контроллер

Используется actor-critic архитектура:

* Actor — выбирает действие,
* Critic — оценивает ценность состояния.

Для непрерывных действий используется гауссова политика:

[
\tilde a_t \sim \mathcal N(\mu_\theta(s_t), \sigma_\theta^2)
]

Фактическое действие ограничивается:

[
a_t = clip(\tilde a_t, 0, u_{max})
]

---

## Функция награды

Награда основана на риск-индексе Коватчева.

Агент получает положительную награду при уменьшении риска:

[
r_t = R_{risk}(G_{t-1}) - R_{risk}(G_t)
]

Дополнительно:

* бонус за нахождение в диапазоне 70–180 мг/дл,
* большой штраф за опасную гипогликемию.

---

## Метрики качества

Для оценки контроллеров используются:

* **TIR** — Time in Range (70–180 мг/дл)
* **TBR** — Time Below Range
* **TAR** — Time Above Range
* **LBGI** — риск гипогликемии
* **HBGI** — риск гипергликемии

## Результаты

Средние результаты за 7 суток моделирования:

| Группа    | Контроллер | TIR        |
| --------- | ---------- | ---------- |
| Взрослые  | PPO        | **81.88%** |
| Подростки | MPC        | **77.24%** |
| Дети      | MPC        | **81.50%** |

Для взрослых PPO показал лучший средний результат и практически устранил гипергликемию (`TAR = 0.50%`).
